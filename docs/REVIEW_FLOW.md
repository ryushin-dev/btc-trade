# レビューの流れ（Claude ⇄ ChatGPT）

Claude と ChatGPT は直接つながっていないため、GitHub の PR を共通の場にして、Ryushin さんが仲介します。

## Claude が出した PR を ChatGPT にレビューしてもらう

1. PR の URL 末尾に `.diff` を付けて開き、内容をコピー（例: `https://github.com/<owner>/btc-trade/pull/1.diff`）
2. ChatGPT に下のプロンプトと一緒に貼る
3. ChatGPT の指摘をそのまま Claude のスレッドに貼る。Claude が反映するか、理由をつけて反論します

```
あなたは暗号資産の自動売買に詳しいシニアエンジニアです。
以下は bitbank BTC/JPY 向け自動売買ツールの差分です。目標は「手数料込みで微小でもプラス」です。
次の観点でレビューし、重要度（高/中/低）を付けて箇条書きで指摘してください。

1. バックテストの先読み（未来の情報を使っていないか）
2. 約定・手数料・スリッページの扱いが楽観的すぎないか
3. 戦略ロジックの誤り、過剰最適化の兆候
4. 実弾運用時の事故リスク（二重発注、残高不足、例外処理、APIキーの扱い）
5. その他のバグ

--- 差分 ---
（ここに貼る）
```

## ChatGPT の案を Claude にレビューしてもらう

ChatGPT が書いたコードや戦略案をスレッドに貼ってください。Claude が同じ観点でレビューし、良ければ PR にして取り込みます。

## 戦略 PR に必ず載せるもの

- バックテストの期間・データ・パラメータ
- `python -m btc_trade backtest ... --json` の出力（手数料込み損益、ドローダウン、約定数）
- 学習期間と検証期間を分けた結果（過剰最適化を避けるため）
